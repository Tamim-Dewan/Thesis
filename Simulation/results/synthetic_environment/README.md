# Synthetic Simulation Environment Views

These are the selected synthetic-environment views for the thesis
demonstration. The numeric prefix is the recommended presentation order.

| Order | File | Represents |
| --- | --- | --- |
| 1 | `01_synthetic_source_map.html` | Source synthetic building footprints and the simulation map extent. |
| 2 | `02_synthetic_building_layout_3d.html` | 3D pre-earthquake/source layout with the synthetic buildings and operating base. |
| 3 | `03_synthetic_damage_moderate.html` | Moderate post-earthquake damage with intact, minor, major, and destroyed states. |
| 4 | `04_synthetic_operational_environment.html` | Main synthetic operational scene with damage objects, 6 survivor tasks, and UAV drop-off waypoints. |
| 5 | `05_synthetic_collision_geometry.html` | Collision volumes used for safe navigation: ground and elevated blocked regions. |
| 6 | `06_synthetic_damage_severe_stress_test.html` | Severe-damage stress-test configuration; optional for the main presentation. |

For a short comparison/demo, open files 1, 3, 4, and 5. The other
`synthetic_*.html` file in the parent `results` directory is retained as an
older or duplicate export so existing commands and references are not
disrupted.
