# Synthetic Simulation Environment Views

These are the selected synthetic-environment views for the thesis
demonstration. The numeric prefix is the recommended presentation order.

| Order | File | Represents |
| --- | --- | --- |
| 1 | `02_synthetic_building_layout_3d.html` | 3D pre-earthquake/source layout with the synthetic buildings and operating base. |
| 2 | `03_synthetic_damage_moderate.html` | Moderate post-earthquake damage with intact, minor, major, and destroyed states. |
| 3 | `04_synthetic_operational_environment.html` | Main synthetic operational scene with damage objects, 6 survivor tasks, and UAV drop-off waypoints. |

For the current supervisor presentation, open files 1, 2, and 3. The source
map, collision geometry, severe stress test, and older duplicate exports are
preserved under the root `archive/` directory.
