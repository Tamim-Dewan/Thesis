# DU Simulation Environment Views

These are the selected University of Dhaka Science Complex views for the thesis
demonstration. The numeric prefix is the recommended presentation order.

| Order | File | Represents |
| --- | --- | --- |
| 1 | `01_du_source_map.html` | Source DU building footprints: 8 mapped target buildings and 16 context footprints. |
| 2 | `02_du_building_layout_3d.html` | 3D pre-earthquake/source layout with buildings, roads, and the operating base. |
| 3 | `03_du_damage_moderate.html` | Moderate post-earthquake damage: intact, minor, major, and destroyed states with rubble/debris. |
| 4 | `04_du_operational_environment.html` | Main operational scene with damaged buildings, base, survivor tasks, and UAV drop-off waypoints. |
| 5 | `05_du_collision_geometry.html` | Collision volumes used for safe navigation: ground and elevated blocked regions. |
| 6 | `06_du_damage_severe_stress_test.html` | Severe-damage stress-test configuration; optional for the main presentation. |
| 7 | `07_du_map_completeness_audit.html` | Data/template coverage audit; use as technical validation, not as the main scene. |

For a short viva/demo, open files 1, 3, 4, and 5. The other `du_*.html`
files in the parent `results` directory are retained as older or duplicate
exports so existing commands and references are not disrupted.
