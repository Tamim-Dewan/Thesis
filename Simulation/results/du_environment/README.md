# DU Simulation Environment Views

These are the selected University of Dhaka Science Complex views for the thesis
demonstration. The numeric prefix is the recommended presentation order.

| Order | File | Represents |
| --- | --- | --- |
| 1 | `02_du_building_layout_3d.html` | 3D pre-earthquake/source layout with buildings, roads, and the operating base. |
| 2 | `03_du_damage_moderate.html` | Moderate post-earthquake damage: intact, minor, major, and destroyed states with rubble/debris. |
| 3 | `04_du_operational_environment.html` | Main operational scene with damaged buildings, base, survivor tasks, and UAV drop-off waypoints. |

For the current supervisor presentation, open files 1, 2, and 3. The source
map, collision geometry, severe stress test, completeness audit, and older
duplicate exports are preserved under the root `archive/` directory.
