# PGBM Initial Solution V2

This folder contains the Version 2 comparative report for the formulation
aligned one-for-one task replacement recourse experiment. The V2 report keeps
the Version 1 findings flow, puts the V2 core mechanism first, and compares V1
and V2 on the same seeded scenarios.

The report is generated only after the paired experiment matrix, decision
traces, aggregation, and LaTeX compilation have been verified.

The report uses four vector PDF figures under `../assets/v2/`. They are built
from the paired metrics and decision evidence by `Simulation/report_charts.py`.
