# Archived generated artifacts

This directory contains generated views, exploratory outputs, and temporary
quality-assurance material that are not part of the active thesis workflow.

The active simulator source, tests, thesis source, report source, benchmark
code, and heiDATA sample data remain in their original locations. Current
presentation demos and canonical V1/V2/V2.1 evidence also remain under
`Simulation/results/`.

The archive preserves the original filenames so an artifact can be restored
by moving it back to its former location if needed.

Current groups include:

- `Simulation/results/heidata_*`: large exploratory heiDATA environment runs.
- `Simulation/results/{du_environment,synthetic_environment}`: source maps,
  collision views, audits, and severe stress-test previews no longer used in
  the presentation.
- `Simulation/results/legacy_*`: older previews, snapshots, metrics, and
  unused image captures.
- `Simulation/results/pgbm_v1_two_hour_experiments/`: superseded static views.
- `Supervisor Presentation/`: generated build caches and older PPTX exports.
- `tmp/`: temporary PDF QA renders.
- `metadata/`: macOS `.DS_Store` files and pytest caches.
